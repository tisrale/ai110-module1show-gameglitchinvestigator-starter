### Game purpose

Glitchy Guesser is a number guessing game built with Streamlit. The game picks a secret number in a range that depends on the difficulty (Easy 1–20, Normal 1–100, Hard 1–50). The player has a limited number of attempts to guess it (Easy 6, Normal 8, Hard 5). After each guess the game gives a hint, and the score goes down for wrong guesses and up for a win, with more points for winning in fewer attempts. The code was generated by AI and shipped with bugs. My job was to find and fix them.

### Bugs found

When I first ran the game, the Developer Debug Info showed it had already started: attempts was 1 with 8 allowed and 7 left, even though I hadn't entered anything and the history was empty.

| # | Bug | Expected | What I saw |
|---|-----|----------|------------|
| 1 | Attempts started at 1 | Attempts start at 0 and go up with each guess | Attempts was already 1 before any guess, and then went from 1 to 0 |
| 2 | Attempts number was wrong | Attempts count up with each play | It still showed 0 after multiple plays |
| 3 | Attempts left didn't update | Attempts left goes down by one with each guess | It still showed 8 after more than 8 guesses |
| 4 | Unusual score results | The score makes sense for each guess | The score was negative or incorrect |
| 5 | The game crashed | The game plays smoothly | It stopped responding after a few attempts |

### Fixes applied

- **Refactor:** I moved `get_range_for_difficulty`, `parse_guess`, `check_guess` and `update_score` from `app.py` into `logic_utils.py` so they can be tested with pytest.
- **Attempts:** Attempts now start at 0 and only go up for a valid guess. The status box is filled in after the guess is processed, so "Attempts left" is always current.
- **Score:** A win now scores `100 - 10 * (attempt - 1)`, with a minimum of 10. Every wrong guess costs 5 points, whether it was too high or too low. The secret is always compared as a number. A negative score early on is expected: it just means you guessed wrong before winning.
- **New Game:** It now resets attempts, score, status and history.
- **Tests:** `tests/test_game_logic.py` has 24 pytest cases. They cover the scoring rules, the comparison of guesses with the secret, and the attempt fixes. The attempt tests run the real app with Streamlit's `AppTest`.

**Known issues not fixed yet:**
- The hint messages are still backwards: "Too High" says "Go HIGHER!"
- New Game always picks the secret from 1–100, ignoring the difficulty.
- The info box always says "between 1 and 100".
